# PPC Wiki

PPC Wiki is the Purdue Photo Wiki repository.

The main purpose is to help people who are beginning in photography. It has notes, guides, and resources about camera basics, composition, editing, film, gear, and other photography topics that are useful for Purdue Photography Club members and anyone else learning.

The site is built with [Astro](https://astro.build/) and [Starlight](https://starlight.astro.build/). It is hosted on Cloudflare Pages.
